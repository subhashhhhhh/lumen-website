MediaFrames

object MediaFrames(source)

The stills Smart Search looks at. A photo: Android's cached thumbnail. A video: one frame a second up to two minutes (exact moments, not just keyframes), then MaxFrames spread evenly, so a long video costs about what a two-minute one does. Frames that look like the last one kept are skipped before the model ever sees them: a talking head or a still shot doesn't fill the index with copies.

Calls onFrame with each frame's time (0 for a photo) and pixels, at most px on their long side; stops if it returns false. skipSame: leave out frames that look like the last one (Smart Search, faces); the text pass wants them all, since a new caption over the same shot barely changes a small thumbnail, and it skips unchanged lines itself.
