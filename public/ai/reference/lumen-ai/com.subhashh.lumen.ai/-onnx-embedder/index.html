OnnxEmbedder

class OnnxEmbedder(dir: File, spec: OnnxSpec, threads: Int, gpu: Boolean = false) : Embedder(source)

A CLIP-style model (two encoders, one shared space). Text always runs on ONNX Runtime's CPU provider. The image encoder does too, unless OnnxSpec.visualFile is a LiteRT .tflite: then it runs on the GPU when gpu is set (only after GpuCheck passed on this phone) and on LiteRT's CPU path otherwise. dir holds the files named in spec.
