FaceStore

class FaceStore : SQLiteOpenHelper(source)

Faces found in photos and the people they're grouped into. Same lifecycle as EmbeddingStore: app-private, not backed up. People carry what the user decides (names, merges, hidden), so grouping only ever adds faces to people; it never moves a face that already has one.
