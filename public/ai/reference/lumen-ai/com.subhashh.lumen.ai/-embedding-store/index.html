EmbeddingStore

class EmbeddingStore : SQLiteOpenHelper(source)

Smart Search's index for one model: which library items are done (at which version) and their vectors. A photo has one vector; a video one per kept frame, with the frame's time. One file per model, in app-private storage that isn't backed up, since vectors from different models can't be mixed and are cheap to rebuild.
