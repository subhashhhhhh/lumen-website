TextStore

class TextStore : SQLiteOpenHelper(source)

The words read from each photo, in a full-text index (SQLite FTS4, unicode61: case- and accent-insensitive), so a search for a name or a phrase finds every screenshot containing it. Same lifecycle as EmbeddingStore: app-private, not backed up, rebuilt if lost.
