FaceGrouping
Link copied to clipboard
object FaceGrouping

Groups faces into people, Immich-style and incremental: a face that has no person joins the person of its most similar face that has one, if that's at least SamePerson alike. Else, if MinFaces − 1 other unassigned faces are that alike, they start a new person together. Otherwise it waits for more faces of whoever it is. Faces with a person never move: that's the user's to change (merge, split).

FaceIndexer
Link copied to clipboard
class FaceIndexer(context: Context, model: AiModel?)

One faces pass: brings FaceStore in line with the library, then groups new faces into people (FaceGrouping). Photos first, newest first; then videos, read like Smart Search reads them (one frame a second up to two minutes, else 120 spread out, near-identical frames skipped) at the Video Detail size, decoded a few frames ahead on another thread. A video keeps one face per person in it, the biggest, with its moment and a saved crop; otherwise one reel would outweigh a whole album. The first pass of the background job: it's the fastest.

FrameCache
Link copied to clipboard
object FrameCache

Video frames kept between passes, so a video is decoded once: the faces pass saves each frame small (shortest side Side, what Smart Search's models look at), the Smart Search pass reads them back and deletes them. Decoding was most of a video's cost (~0.3 s a frame); saving and reading a small JPEG is a few ms. One folder per video; done marks a complete set, so a pass stopped mid-video doesn't leave Smart Search with half its frames.

GemmaBpeTokenizer
Link copied to clipboard
class GemmaBpeTokenizer(file: File)

SigLIP 2's text tokenizer (Gemma's 256k BPE), read from the compact file that tools/models/pack_gemma_tokenizer.py makes from tokenizer.json. Matches OpenCLIP's "canonicalize" cleaning: no ASCII punctuation, lower case, single spaces. Then BPE over the whole string (spaces as ▁), unknown characters as UTF-8 byte tokens, <eos>, zero padding. Checked against the official tokenizer on English, Hindi, Telugu and emoji queries.

Indexer
Link copied to clipboard
class Indexer(context: Context, model: AiModel)

One indexing pass: brings a model's EmbeddingStore in line with the library. Items that were deleted (or moved into an excluded folder) are dropped. Then photos, newest first, so search covers them within minutes; then videos, whose frames are decoded on another thread into a small queue while the model works (decoding is mostly the phone's video hardware, the model the CPU, so the two overlap almost for free). Cancellation keeps everything finished so far; the next pass carries on.

object LiveText

Live Text: the text in the photo on screen, with where every character is, so it can be selected and copied. object MediaFrames

The stills Smart Search looks at. A photo: Android's cached thumbnail. A video: one frame a second up to two minutes (exact moments, not just keyframes), then MaxFrames spread evenly, so a long video costs about what a two-minute one does. SmartSearch
Link copied to clipboard
object SmartSearch

Searching by meaning: the query goes through the model's text half (tens of ms) and is compared with every indexed photo and video frame (a flat scan; a few ms per thousand). A video scores as its best-matching frame. The vectors stay in memory between searches and are reloaded only when the index has changed.

SpeechDetector
Link copied to clipboard
class SpeechDetector(dir: File) : AutoCloseable

Where people speak in 16 kHz audio: Silero VAD v6 (MIT, 1.3 MB) on ONNX Runtime. Whistle invents sentences ("Thank you.", "Vielen Dank.") from music, and most edits are music, so only what this marks as speech is transcribed. TextIndexer
Link copied to clipboard
class TextIndexer(context: Context)

One text-reading pass: brings TextStore in line with the library, newest first: photos, then videos. A video is read frame by frame like Smart Search reads it (Video Detail size), but only lines that changed are read again (TextReader.readChanged): captions stay up for many frames. object Whistle

Speech to text with Cactus Compute's Whistle (Apache 2.0, 16.9 MB): English, German, French, Spanish, Italian, Dutch and Polish, with word timings.
