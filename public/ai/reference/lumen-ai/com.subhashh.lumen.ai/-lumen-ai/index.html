LumenAi

object LumenAi(source)

Lumen AI's entry point.

Install it once, in Application.onCreate, before anything else here runs: background indexing and model downloads start in their own process launches and need it.

LumenAi.install(this)                       // every photo and video, default settings
LumenAi.models.download(context, ModelPack.Search)
val results = LumenAi.search(context, "cat sleeping on a chair")

search
Link copied to clipboard
suspend fun search(context: Context, query: String): SearchResults

Searches the library, the way Lumen does. Words in quotes find that exact phrase in the text of photos and videos. Two or more names find the photos with all of those people. Otherwise, photos whose text has the words come first, then Smart Search's matches. Uses whichever features are downloaded; empty results when none are.
